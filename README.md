# Bildspel

Presentationsverktyg för en Chromebook kopplad till smartboard. Planera lektioner, klistra in bilder, skriv på sidorna, importera PDF och Google Presentationer, visa video, YouTube och timer.

**Öppna:** https://magnusmac.github.io/bildspel/

- Allt sparas i webbläsaren på datorn. Använd *Spara fil* som säkerhetskopia.
- Knappen *Hjälp* (eller F1) i appen förklarar allt.
- Hela appen är filen `index.html`. Den går också att ladda ner och öppna direkt i Chrome utan internet (YouTube öppnas då i en ny flik).

Made by Magnus MacNeil.

Innehåller pdf.js från Mozilla (Apache 2.0), se `LICENSE-pdfjs.txt`.
Källkoden utvecklas i ett annat repo; den här mappen byggs med `python3 bygg.py`.
